Privacy policy

Clip Uploader is a personal tool used only by its owner.

What it accesses

With the owner's permission, it uses the YouTube Data API for one purpose: uploading videos to the owner's own YouTube channel.

What it stores

The sign-in token is stored only on the owner's own computer. No data is collected from anyone else, and nothing is shared with or sold to third parties.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Clip Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy.
